# Carousel images

| File            | Slide                                          |
|-----------------|------------------------------------------------|
| `community.png` | UFCU team event — "The UFCU Way"               |
| `branch.png`    | Branch exterior — "It all starts with U"       |
| `service.png`   | Member being helped at a branch desk           |

Supplied by the team from UFCU's own marketing photography. Any slide whose
file is missing falls back to a drawn brand panel, so the carousel still works
if these are removed.

If you swap or add images, keep them landscape-ish and reasonably large; they
are cropped with `object-cover` into a fixed-height slide, so the subject wants
to sit near the horizontal centre.

**Two things not to add:** other institutions' logos or marks, and the real
collegiate debit-card artwork. The card faces in the carousel are drawn in our
own shapes using only the schools' colours for that reason.
